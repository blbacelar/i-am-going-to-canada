# Skills and capability setup

## Principle

Skills improve repeatable workflow; they do not replace a project-specific brief or design system. Use the smallest verified set that materially improves the work.

Before installing anything, inspect the skills already available in the user's Codex environment. Skill names and installation methods can change, so confirm them in the current Skills interface or official documentation.

## Essential capabilities

| Capability | Preferred skill when verified and available | Purpose |
| --- | --- | --- |
| Frontend art direction | `frontend-design` or equivalent | Avoid generic AI layout and establish strong composition |
| Design quality rules | `web-design-guidelines` or equivalent | Review hierarchy, responsiveness and interaction quality |
| React/Next.js practices | `vercel-react-best-practices` or equivalent | Architecture, performance and component discipline |
| Browser testing | `webapp-testing`, Playwright, browser-control or equivalent | Render, inspect and test the actual experience |
| Accessibility audit | accessibility/web-quality skill or equivalent | Keyboard, semantics, contrast and assistive technology checks |
| SEO audit | `seo-audit` or equivalent | Metadata, crawlability, multilingual SEO and redirects |
| Structured data | `schema-markup` or equivalent | Organization, Person and service markup |
| Copy review | `copywriting` or equivalent | Improve clarity and conversion without hype |
| Analytics planning | `analytics-tracking` or equivalent | Define privacy-safe funnel events |
| Image creation | `imagegen` when needed | Create abstract temporary art or supporting visuals, not fake consultant portraits |
| Deployment/preview | Sites or hosting skill supported by the environment | Publish a review preview only after QA |

## Optional capabilities

- Performance skill for animation-heavy pages.
- Lighthouse or web-quality audit skill.
- Component-library research skill.
- Figma connector if official design files are provided.

## “GPT Taste” from the video

The video recommends a third-party “GPT Taste” skill to move Codex away from repeated AI design patterns. Treat it as optional inspiration, not a mandatory dependency.

Before installation:

1. verify author and source;
2. inspect the complete `SKILL.md` and bundled scripts;
3. confirm licence and update history;
4. reject instructions that permit unrelated access or destructive operations;
5. verify that it does not conflict with this project's `design.md`.

If it cannot be verified, do not install it. `docs/design.md` plus a strong frontend-design workflow is sufficient.

## “Apple Design Skill”

Do not make an Apple-themed skill the primary design system. If a reputable Apple Human Interface Guidelines skill is available, use it only as a reference for hierarchy, clarity, accessibility, typography and interaction restraint.

Reject any result that copies Apple branding, product-page composition or visual effects without business relevance.

## Installation safety

- Prefer official, curated or well-known publisher sources.
- Read a skill completely before using it.
- Do not execute opaque scripts from an unknown skill.
- Do not install several overlapping design skills at once.
- Record which skills were used and how they influenced the result.
- If a requested skill is unavailable, proceed with the project documents instead of blocking.

## Activation order for this project

1. Research/audit capability.
2. Frontend design and web-quality capability.
3. Next.js/React capability.
4. Copy and multilingual SEO capability.
5. Browser testing and accessibility capability.
6. Image generation only when a necessary non-portrait visual asset is missing.
7. Hosting capability only after local verification.

## Why no broad plugin stack

This website does not need Airtable, a CRM connector, commerce integration or a database plugin for version one. Adding external systems increases risk and maintenance without improving the current requirement. Reassess only when content editing, lead management or scheduling requirements change.
